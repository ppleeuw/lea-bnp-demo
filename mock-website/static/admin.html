What the checks in code did, for the selected source. Counts per turn.

Before the agent. Card numbers (Luhn check), PINs and passwords by pattern; typed fake session notes; Mistral moderation: jailbreaking ≥ 0.3 is blocked.
Flagged, not blocked. Personal-data score ≥ 0.5: logged for review. In a bank, "What is my balance?" already scores 0.50.
Refused in code. Banking tools for guests (SIGN_IN_REQUIRED), another customer's ID (CUSTOMER_MISMATCH), unknown card or account.
Card-lock confirmations. Every lock waits for the customer's tap and in-app approval: allowed, denied, or left unconfirmed.
After the agent. The balance in the answer must equal the tool result; "locked" only after a successful lock.
